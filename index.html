Informação pública

Backup pessoal para uma coleção local.

O Relicario Backup é um app local para organizar uma coleção pessoal e preparar cópias de segurança controladas pelo próprio responsável.

O app

A aplicação trabalha com os dados da coleção no ambiente local do responsável. O uso é estritamente pessoal; não oferece cadastro público nem serviço público de catálogo.

O backup

Quando a integração é autorizada e executada, o projeto usa a API do Google Drive com o escopo drive.file, limitado aos arquivos que o app cria ou aos quais o usuário dá acesso.

Controle

Quando ativado, o backup é conferido e a retenção remove somente cópias criadas pela integração, conforme a regra do projeto. O resultado de cada execução depende da configuração e das condições do momento.

Uso pessoal

O Relicario Backup roda no computador do responsável e é destinado a uma coleção privada. Estas páginas apenas apresentam o app e seus limites para uma eventual configuração dos links informativos.

O backup, quando desejado, depende de configuração e autorização do responsável. Consulte a política de privacidade e os termos de uso.
